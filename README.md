# Segment Anything (SAM): learning notebook

This is a learning exercise, kept for reference. It is **not an original method**.

The notebook is Roboflow's public tutorial [How to Segment Anything with SAM](https://github.com/roboflow/notebooks/blob/main/notebooks/how-to-segment-anything-with-sam.ipynb), run in Google Colab and extended with two sections of my own:
- automatic mask generation on my own images;
- box-prompted segmentation on those images, using a drawn bounding box.

My research code on concrete-defect segmentation is in **[concrete-defect-detection-shm](https://github.com/mohamedragab4554/concrete-defect-detection-shm)**.

Credit: Roboflow (tutorial notebook); Meta AI, *Segment Anything* (Kirillov et al., 2023).
